# Features

Sort ideas as we go. Move things between sections freely.

## Must-have (launch)

- [ ] Map: prison, police station, city, criminal base
- [x] Everyone spawns as an inmate; guard rank from applications (on the website)
- [x] Discord ↔ Minecraft account linking (Java + Bedrock), on the website
- [x] Escape → criminal state change at the prison boundary
- [x] Robbery locations with open/close timers and alarms (the places come with the map)
- [x] Bounty system
- [x] Guard handcuffs + taser, arrest → back to prison
- [x] Cash, saved per player
- [x] Shop for basic gear
- [x] Custom guns + ammo (Bedrock still to test)
- [x] Riots
- [x] Guard vs. criminal PvP rules, no direct criminal-on-criminal damage, safe zones (see [combat](02-gameplay.md#combat))
- [ ] Java + Bedrock crossplay, tested on both
- [x] Basic anti-cheat and moderation tools (GrimAC, LibertyBans)
