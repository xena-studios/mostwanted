# Security policy

This code runs a public server with real players.

## Reporting a vulnerability

**Don't open a public issue, and don't test it on the live server.** Instead, either:

- use [private vulnerability reporting](https://github.com/xena-studios/mostwanted/security/advisories/new), or
- email [contact@xenastudios.co](mailto:contact@xenastudios.co) with "Security" in the subject.

Include the plugin version (`/mostwanted info`), steps to reproduce, and the impact.

## What to expect

- A reply within **72 hours**
- An assessment within **7 days**
- A fix on the live server as soon as it's ready
- Credit in the changelog, if you'd like it

## Scope

**In scope:**

- The plugins, website, backend and server setup in this repo
- Getting past a rule the game enforces: escaping without a route, hurting someone you shouldn't, duplicating items or cash, using guard powers without the guard rank
- Crashing or lagging the server out of proportion to what you did

**Out of scope:**

- Problems in Paper, Leaf, Minehut or third-party plugins, unless ours makes them reachable
- What staff can do with permissions they've been given
- Denial of service through volume alone

## Safe harbour

We won't take legal action over good-faith research that follows this policy, only tests on a server you run yourself, and avoids harm to the live server, its players and their data.
