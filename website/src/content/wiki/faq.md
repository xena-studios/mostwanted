## Is the server open?

Not yet. Follow the [news](/news) for the launch.

## What version do I need?

Java **26.3**. Newer Java versions can join too. Bedrock: the current version.

## Can Bedrock players play?

Yes, on phone, console and Windows, through Minehut. Same world, same server as Java players.

## Is it pay to win?

No. The [store](/store) only sells cosmetics: jumpsuit colours, gun skins, trails and chat tags. Nothing that wins a fight, an escape or a robbery.

## How do I become a guard?

Apply when applications open. See [Apply](/apply).

## I found a bug or a cheater

Report it. See [Support](/support). Never use a bug: it's a ban.
