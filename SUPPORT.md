# Getting help

- **Playing on the server:** ask in the server's Discord.
- **Bugs and ideas:** open an [issue](https://github.com/xena-studios/prison-break/issues/new/choose). For a bug, include the version from `/prisonbreak info`, what you did, and any console errors.
- **Security problems:** see [SECURITY.md](SECURITY.md). Never a public issue.
- **Anything else:** email [contact@xenastudios.co](mailto:contact@xenastudios.co).
