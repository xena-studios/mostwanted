# Resource pack

Source art and models for the server's custom items (guns, food, tools, contraband). Not built yet: the plan is in [docs/06-resource-pack.md](../docs/06-resource-pack.md).

- Built into the **Java pack** in CI, and published as a GitHub release (Minehut only accepts packs from approved hosts; GitHub is one).
- A **Bedrock pack** too, if Minehut lets external servers supply one.
- Every custom item is a vanilla item underneath, so the game works without the pack.
